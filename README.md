# DASHBOARD

A dashboard page that lets users manage categories and widgets.

![Home](./public/home.png)

## Features

### 1. Manage categories

> Manage widgets for each category

![manage-category](./public/manage-categories.png)

> Add category

![add-category](./public/add-category.png)

### 2. Add widgets

> Select any category and add widget

![widget-global](./public/add-widget-global.png)

> Add widget for particular category

![widget-local](./public/add-widget.png)

### 3. Search

> Search category or widgets

![search](./public/search.png)

## Installation

### 1. Clone repository

```
git clone https://github.com/arijit-malakar/assignment-dashboard.git
```

### 2. Install dependencies

```
cd assignment-dashboard
npm install
```

### 3. Start dev server

```
npm run dev
```
